cmacs - Terminal Editor
=======================

Install
-------

From a terminal, cd into this directory and run:

    bash install.sh

This installs:
  - cm binary to /usr/local/bin/
  - Help files to /usr/local/share/cm/

macOS Note: Do not run cm directly until you run install.sh.
Downloaded binaries are blocked by macOS Gatekeeper. The installer
clears this restriction automatically.

If double-clicking install.sh does not work, run "bash install.sh"
from the terminal instead.

Try It
------

    cm myfile.txt

Or just run "cm" to start with an empty buffer.
Press Ctrl-H for built-in help.
